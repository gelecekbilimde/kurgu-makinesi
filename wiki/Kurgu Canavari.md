DaVinci resolve studio connected to Claude opus 5.5 via MCP has been a game changer for me. It does cuts titles, graphics, B roll, really anything you need. For example, I edited this recent video almost entirely from a few prompts with opus after giving it my a role talking head footage and my screen recording footage. Feel free to DM me. I can walk you through my process.

It helps to have some familiarity with Claude Code but basically you'd set up a project for Claude Code to work in point it to an empty folder on your computer then tell it what you want to start building out an editing playbook. For me it's something like 'I'll provide you with talking head (A-roll) footage, I will want you to cut this footage down, remove pauses/ums/bad takes, then go find relevant b-roll whether than be screenshots, full video with audio, or graphics/titles you render and apply it at the right points throughout the video. Think high-retention editing, zoom ins-outs with quad ease, text on screen to illustrate key points as I say them'

And it will work with you going back and forth to develop a style. Then that creates your playbook. Then you can start a new chat in that same project/folder and tell it: 'I've created a new subfolder (projectA) that has my A-roll in it along with xyz footage, create a video in Davinci Resolve based on our discussions. Start by just cutting a-roll then I'll review and tell you next steps'

That's a pretty basic starting point but points you to how you'd think about the workflow.
