# Script template (A/V script)

The script template writers use for Gelecek Bilimde episodes, and the tools that read it. The design is in `docs/superpowers/specs/2026-11-11-script-template-design.md`.

**Writers start here:** https://docs.google.com/document/d/1exWuBZ7CdCYZRy5cJa-1Pvlx7HLDrkUE5dSXfGWsI1Y/copy Opening the link makes your own copy. The guide is in the copy's *Kılavuz* tab, and the same text is in `kilavuz.md`.

## Files
| File | What it is |
|---|---|
| `script-template.docx` | generated by `build_template.py`; the starting point of the Google master |
| `rules.py` | the `[TAG]` parsing, the row checks and the duration estimate |
| `speakers.json` | each speaker's reading pace (script words per second) |
| `kilavuz.md` | the writer's guide, in Turkish |
| `script_doc.py` | the reader: an exported `.docx` becomes `script.json`, `script.txt` (for the rough cutter) and `prompter.txt` |
| `docx_build.py` | a minimal .docx writer for the template and the test fixtures |
| `tools/legacy_to_av.py` | converts an old-style `script.txt` into the template layout |

## Using an episode script
1. The writer shares their copy. Download it with File › Download › Microsoft Word (.docx) into `episodes/<slug>/script.docx`.
2. Run `python3 templates/script/script_doc.py episodes/<slug>/script.docx episodes/<slug> --prompter`. It prints the rows with warnings and the length **as written**: each row's SES words at the speaker's pace. The speaker comes from `"speaker"` in `episode.json`, then `--speaker "Name"`, then the script's *Sunucu:*.

The downloaded .docx also contains the *Kılavuz* tab, because Google exports every tab, after the Kaynakça. The reader stops at the Kaynakça, so the guide is ignored.

Tests: `python3 -m unittest discover -s templates/script/tests`.

Durations live only in the reader's output, not in the template: there is no duration column and no script inside the Google Doc. A new speaker gets the default pace until they are measured and added to `speakers.json`.

## Rebuild the master
**Change the repo first, then the master.** The master is a Google Doc owned by the maintainer's account; nobody edits it directly.

1. Run `python3 templates/script/build_template.py`.
2. Upload `script-template.docx` to Drive, open it with Google Docs, and save it as a Google Doc (File › Save as Google Docs). Name it "Senaryo Şablonu".
3. Add a tab named *Kılavuz* and paste the contents of `kilavuz.md` into it.
4. Share › General access: *Anyone with the link*, role *Viewer*.
5. Put `https://docs.google.com/document/d/<ID>/copy` at the top of this README, and commit.
